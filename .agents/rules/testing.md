# Testing Rules

- **Evaluation Metrics**: MVP evaluation must include sensitivity, specificity, ROC-AUC, PR-AUC, F1, QWK, confusion matrix, and calibration metrics.
- **Tasks**: Evaluate both ordinal DR Grade 0–4 and referable DR (Grade >= 2).
- **Integrity**: Never fabricate or estimate metrics. Any metric shown in documentation must come from an actual executed experiment.
